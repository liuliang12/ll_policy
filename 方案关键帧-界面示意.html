F7 · Comate 现状与职责边界

现状校准：Comate 新建任务 = 选触发 + 用自然语言描述任务，尚非画布。文件夹侧与之同构，并靠预设模板的轻量参数降低填写门槛。

夹侧 ≈ Comate 同构 模板参数降门槛 引擎/算粒/托管
能力事实（对齐 Comate 现状）：新建任务 = 选触发 +「用自然语言描述任务」，不是节点画布。 因此对外叙事勿承诺「打开 Comate 就能可视化增删节点」——除非 Comate 排期交付编排流能力。
策略说明（夹 ↔ Comate）
MVP · 夹侧与 Comate 同构
· F3：触发单独拆出；任务内容=编号步骤 + 行内 Skill
· 预设：各 Skill 动态参数做成表单，改完回写任务内容
· Comate：执行引擎 + 算粒 + 按 NL 任务托管
用户改任务 → 优先回夹侧参数/描述，不假设 Comate 画布
「在 Comate 中打开」做什么
· 查看/管理已托管的触发任务
· 查看运行记录、NL 任务内容（只读，不可直接编辑）
· 扩展非「进夹」类触发（可能解绑）
标签建议：已在 Comate 托管（勿写「已可视化编排」）
增长期 · 多流 / 真编排流
· 夹内仍单入口列表；读可并、写唯一
· Comate 管全局；夹管「与本夹相关」
· 若 Comate 交付可视化编排流，再升级「深编排」叙事
清晰画布能力 = Comate 侧依赖，需立项确认

立项前 · 四大依赖（P0，先锁再排期）
这四块不定，MVP 闭环无法承诺。UI 壳相对可控；其它确认项暂不展开。
① 文件夹触发 · 事件通知能力
上传 / 移入（等）进夹动作，是否已有现成事件通知可订阅？没有则本闭环第一环落空。
□ 文件上传到文件夹是否有稳定事件（含批量）？
□ 文件从其它位置移入本夹是否有事件？复制进入是否覆盖？
□ 夹内打开编辑后保存能否排除（避免误触发）？
□ 事件载荷是否含：文件 ID、夹 ID、操作者、时间？投递延迟/可靠性如何？
□ 谁提供（云盘开放平台 / 现有消息总线）？MVP 窗口内能否直接复用、要不要新开？
② AiDocs 开放能力
能否被流程调用，并返回审查结果链接；链接的查看 / 编辑权限如何控？
□ 按模板/规则 ID 异步调用文档审查？补充自定义需求能否传入？
□ 回调是否稳定返回：任务状态 + 审查结果链接 + 风险结论（有/无）？失败/超时错误码？
□ 结果链接：审批人默认可查看？能否限制不可编辑正文/不可改审查结论？处理人改文档走的是当前文档链接而非改报告？
□ 链接权限如何授权给「确认修改人 / 定稿人 / 修改人」（按人临时授权 or 继承文件权限）？
□ 文件夹侧「选用已有模板 + 深链管理模板 + 新建回填」是否支持？
③ 轻审批开放能力 · 要不要「一人节点一模板」？
每人节点各发起一次轻审批；表单必带当前文档链接 + AiDocs 结果链接；处理人可配；标题=流程名·节点名。
□ 能否程序化发起轻审批（API）：指定处理人、会签/或签、自定义表单字段、标题？
□ 通过 / 不通过 /「完成修改并提交定稿」/「重新提交」能否回写 run？
□ 4b 通过后触发「回到节点 2」事件能否接上？
模板策略（建议对齐口径，勿默认「一夹一人节点一模板」）：
· 不推荐：每个文件夹、每个人工节点都去运营后台建一张静态审批模板（爆炸、难维护）。
· 推荐 A：产品级 2～3 类节点模板（完成修改提交定稿 / 定稿审核 / 改稿重提），夹侧只配处理人+注入双链接与文案。
· 推荐 B（更优）：一个动态表单能力——发起时传 schema（标题、字段、按钮），不按夹复制模板。
· 待确认：轻审批侧实际支持 A 还是 B？会签是否已有？
④ Comate 流程编排规划 · 是否对得上本需求？
我们要的是：夹侧把「触发 + NL 任务描述」下发给 Comate（与现状新增任务形态对齐）+ 进夹挂载 + 运行记录；预设参数表单是夹侧 UX，不要求 Comate 先有画布。
□ 夹侧生成的 NL 任务内容，Comate 能否原样托管执行（用户无需到 Comate 从空白重写）？
□ 进夹触发、一夹一条主挂载、解绑策略，Comate 侧能否支撑？
□ Comate 可视化编排流产品规划/排期？与本项目时间窗是否错位？错位则维持 NL 托管叙事。
□ 未交付画布前：对外统一说「已在 Comate 托管」，不说「已可视化编排」——产品/销售是否同意？
落地难点优先级： ① 文件夹进夹事件通知是否现成 → ② AiDocs 调用+结果链接权限 → ③ 轻审批动态表单/节点模板策略 → ④ Comate 能否按夹侧 NL 任务托管执行 vs 画布规划是否对齐。
MVP · 一夹一条（主触发唯一）
锁 folder_id 作为「进入文件夹」主触发唯一；归档等参数引用不占名额。三道闸：云盘不开第二条新建 / 绑定表唯一 / 改触发则解绑。
增长期备忘
夹侧不接复杂画布：挂载/摘要/启停/记录/跳转；多流仍单入口列表；Comate 全局，夹管相关；读可并、写唯一。
多规则冲突：读可并行；写互斥/优先级；通知宜合并（矩阵蓝图，非本期交付）。
不做新产品、不新建计费、不替代 OA。MVP 先锁四大依赖：进夹事件 · AiDocs 开放 · 轻审批发起形态 · Comate 按 NL 托管/下发对齐。可视化编排流与一夹多流为增长期。
